# ADR-019: autoresearch 이식 — 실험은 자동, 배포는 사람 승인

> Feature: F027 — 카파시 autoresearch 를 활용한 localllm 능력 향상
> 상태: `Accepted` (구현 — localllm d-2 오버레이, 실험 2건 + 재현 실험 실측)
> 관련: ADR-010(스킬 활성화 게이트 — autoresearch 교훈 최초 인용), ADR-014(loop engineering),
> ADR-018(결정론 supervisor), 측정 08(무인 스위트 = 적합도 함수)

## 맥락

`karpathy/autoresearch` 는 이 저장소에 **교훈으로만** 들어와 있었다. ADR-010 이 스킬 자동생성
게이트를 정당화하며 *"결과는 가설이지 배포물 아님"* 을 인용했고, 측정 04 가 하이브리드 권고에
*"결과는 shipped improvement 가 아니라 starting hypothesis"* 를 인용했다. 메커니즘은 어느
변형에도 없었다.

원본의 구조는 단순하다:

| 원본 파일 | 역할 |
|---|---|
| `prepare.py` | 고정 — 에이전트가 건드리지 않는다 |
| `train.py` | **유일한 변경 대상** — 에이전트가 매 반복 수정한다 |
| `program.md` | 사람이 쓰는 지침 — 연구자는 코드가 아니라 이 파일을 고친다 |

루프는 `읽기 → 수정 → 5분 고정 예산 실행 → val_bpb 측정 → keep/discard → 반복`이고,
사람은 밤새 쌓인 로그를 검토하고 `program.md` 를 손본다.

이식을 **지금** 할 수 있게 된 이유는 F026 에서 적합도 함수가 생겼기 때문이다. 무인 스위트는
oracle 11종으로 159회 실행에서 거짓 결과 0을 기록했다. 측정기 없이 자동 실험을 돌리면
"좋아 보이는 변경"을 쌓게 될 뿐이다.

## 결정

### 결정 1 — 변경 표면은 "역할 지시(정책)" 하나로 좁힌다

`train.py` 상당은 `.claude/policy/<role>.md` 다. `cycle_driver` 가 역할 에이전트를 호출할 때
과제 앞에 붙이는 5줄 이내 지시문이며, 그 외 어떤 파일도 실험이 바꾸지 않는다.

게이트·oracle·시나리오·드라이버는 `prepare.py` 상당으로 **불변**이다. SHA-256 매니페스트를
실험 전후로 비교해 하나라도 바뀌면 점수와 무관하게 **실험 무효**로 기록한다.

측정 08 의 결론과 맞물린다 — 거짓 결과를 막는 것은 판정 압박이 아니라 결정론 게이트다.
그 게이트를 실험이 손댈 수 있게 두면 최적화 압력이 곧바로 측정기를 향한다.

### 결정 2 — 자동 채택은 "실험 결과"까지, 하네스 반영은 사람 승인

승자 정책은 `.claude/state/autoresearch/best/` (실험 공간)에 머문다. 하네스 본체
`.claude/policy/` 로 옮기는 것은 `promote <exp> --yes` 로만 가능하며, `--yes` 없이는 변경
내용과 근거만 출력하고 아무것도 쓰지 않는다.

autoresearch 의 "starting hypothesis" 를 **디렉토리 경계로** 구현한 것이다. ADR-010 이 스킬을
draft/활성 경로로 갈라놓은 것과 같은 패턴이며, 여기서 처음으로 그 규율이 *생성물*이 아니라
*하네스 자신의 설정*에 적용된다.

### 결정 3 — reward hacking 은 규칙이 아니라 구조로 막는다

정책 문구를 검열하는 키워드 필터는 두지 않았다 (우회하기 쉽고 오탐이 많다). 대신:

| 공격 경로 | 차단 |
|---|---|
| 게이트·oracle 을 무르게 수정 | 불변 매니페스트 해시 검사 → 실험 무효 |
| 테스트 약화·검증 우회를 지시 | 기존 보호 게이트(S10)·vacuous test 검사가 실행 단계에서 차단 |
| 판정을 통과시키는 방향으로 최적화 | 후보 구간에 ACCURACY(거짓 결과) 1건이면 **점수 무관 실격** |
| 측정기가 오작동한 구간의 점수 채택 | 어느 구간이든 BUG(하네스·oracle 결함) 발생 시 **실험 무효** |

점수를 올리는 유일한 길이 "실제로 통과하는 산출물" 이 되도록 유인을 정렬한다.
(BUG 무효 규칙은 측정 09 의 exp-002 에서 후보 구간 BUG 1건을 관측한 뒤 추가했다.)

### 결정 4 — 베이스라인은 같은 배치에서 다시 측정한다 (paired)

원본은 직전 최고 점수와 비교하지만, 우리 적합도 함수는 LLM 확률성 때문에 분산이 크다.
매 실험에서 챔피언 정책을 **다시 돌려** 후보와 같은 조건에서 비교한다. 낡은 기준선과의 비교는
운을 개선으로 오인한다.

### 결정 5 — localllm 변형 전용

autoresearch 가 성립하려면 ① 무인 적합도 함수 ② 무인 드라이버 ③ 실험을 반복해도 비용이
과하지 않은 실행 환경이 모두 필요하다. 현재 이 셋을 갖춘 변형은 `localllm` 뿐이다
(스위트·`cycle_driver` 는 d-2 오버레이, 추론은 로컬 GPU 라 실험당 추가 과금이 없다).

다른 변형에 넣지 않는다. 특히 Claude Code 계열은 실험 1건이 스위트 2회 실행이라 **사람이
없는 밤에 유료 토큰을 태우는 루프**가 되고, 애초에 적합도 함수(스위트)가 없어 측정할 대상이
없다. LINT-MR-9(d-2 격리)에 `autoresearch.py` 와 `.claude/policy/` 를 등재해 유출을 막는다.

> 승격 조건: 다른 변형이 **자기 무인 스위트**를 갖게 되면 그때 이식을 재검토한다.
> 그 전까지 이식은 "돌아가는 척하는 루프" 를 늘릴 뿐이다.

## 원본과의 차이 (의도된 이탈)

| 항목 | karpathy/autoresearch | 이 이식 | 이유 |
|---|---|---|---|
| 변경 대상 | `train.py` — 모델·옵티마이저·학습루프 **코드 전체** | 역할 지시문(자연어) 5줄 | 우리 산출물은 학습 곡선이 아니라 SDLC 결과물. 코드를 열어주면 최적화 압력이 게이트로 향한다 |
| 지표 | val_bpb — 연속값, 저분산 | 스위트 PASS 율 — 이산·고분산 | 적합도 함수의 성질이 다르다 → paired 비교와 반복이 필수 |
| 예산 | 5분 wall-clock 고정 | 시나리오 집합 × 반복 수 고정 | 사이클 길이가 과제마다 달라 시간 고정은 과제 난이도를 왜곡한다 |
| 실패 취급 | 점수 나쁘면 discard | discard + **실격(거짓 결과)** + **무효(불변 위반)** 3분류 | 나쁜 결과와 부정한 결과를 구분해야 원장이 의미를 갖는다 |
| 채택 | 에이전트가 keep 하면 그대로 다음 반복의 기준 | keep 은 실험 공간까지, 본체 반영은 사람 승인 | 우리 산출물은 다운스트림이 가져가는 하네스다 |
| 사람의 역할 | `program.md` 편집 + 로그 검토 | **동일** | 원본에서 가장 잘 설계된 부분이라 그대로 가져왔다 |

## 대안 검토

- **hill_climb 에 자동 적용 붙이기**: 기각. hill_climb(Loop 4)은 신호·후보 산출까지이고
  auto-apply 금지가 ADR-014 의 결정이다. 실험·증거 단계를 건너뛴 자동 적용은 그 결정을 뒤집는다.
  autoresearch 는 hill_climb 이 멈춘 지점(후보)부터 시작해 증거를 만들어 붙인다.
- **정책이 아니라 드라이버 코드를 진화 대상으로**: 기각. 결정 1·3 참조 — 측정기를 진화 대상에
  포함시키면 측정이 무의미해진다.
- **통계 검정(부트스트랩 등) 자동 판정**: 보류. 현재 표본(실험당 4~6회)에서는 어떤 검정도
  검정력이 없다. 승격 판단을 사람에게 남기고 원장에 원자료를 남기는 편이 정직하다.

## 결과

실험 2건 + 재현 실험으로 확인된 것:

- 루프는 설계대로 동작한다 — KEEP / DISCARD / 실격 / 무효 4분류가 모두 코드 경로로 존재하고,
  실측에서 KEEP 과 DISCARD 가 각각 발생했다.
- **첫 실측의 결론은 "승자 정책" 이 아니라 "표본이 노이즈에 지배된다"** 였다. 거의 같은 문구의
  정책이 4/4 와 1/4 로 갈렸다. 자동 승격이었다면 운을 개선으로 배포했을 것이다.
- **재현 실험이 KEEP 을 반증했다**: exp-001 이 KEEP 한 정책(0/4 → 2/4)을 빈 정책과 같은 배치에서
  3라운드씩 교차 측정하니 **3/6 대 3/6 동률**이었다. 개선은 재현되지 않았다.
- 결정 2(사람 승인 게이트)의 가치가 첫 실험에서 곧바로 실증됐다 — 이 ADR 을 쓰는 시점에도
  승격된 정책은 없다.

# deprecated — 비활성 변형 보관소

> 2026-10-23, 사용자 지시. 활성 변형을 **`claude.loope` · `claude.vela.v0.1` · `localllm`
> 셋**으로 좁히고 나머지를 여기로 옮겼다.

## 왜 옮겼나

변형이 16개가 되면서 미러 계약을 지키는 비용이 산출물의 가치를 넘어섰다. F021 이
리뷰 6라운드를 도는 동안 결함의 상당수가 "수정이 16 사본에 다 가지 않았다" 였다.
**셋으로 줄이면 그 표면이 1/5 이 된다.**

## 보관 원칙

- **지우지 않는다.** `git mv` 라 이력이 보존된다 — 되살리려면 되옮기면 된다.
- **drift 검사는 면제, 동결은 그대로.** 둘은 반대 방향의 사실이라 함께 끄면 안 된다.

  | 검사 | 묻는 것 | 보관소에서 |
  |---|---|---|
  | `LINT-MR` · `LINT-CO` · `LINT-SSOT` | "뒤처졌는가" | **면제** — 뒤처져도 BLOCK 이 나지 않는 것이 deprecated 의 뜻이다 |
  | `LINT-FREEZE` | "바뀌었는가" | **그대로 강제** — 아무도 손대지 않을 곳일수록 이 가드는 싸다 |

  > 처음엔 동결도 함께 껐다(INFO 강등). **틀린 판단이었다** — 매니페스트 53 경로의
  > 해시가 `deprecated/` 접두만 끼우면 **53/53 그대로 맞았다**. 공짜로 유지되는
  > 가드를 버린 것이고, 되돌렸다. `freeze-manifest.json` 은 이제 보관소 경로를 가리킨다.

  drift 면제를 막는 것은 두 겹이고, 둘이 막는 모양이 다르다:

  | 겹 | 무엇이 막나 | 뒤집는 변경 |
  |---|---|---|
  | **깊이** | 보관된 변형은 `deprecated/<이름>/harness` 로 **한 단 깊다**. 변형 탐색(`_co_collect`)은 `src/harness_template/` 를 **한 단만** 순회하므로 닿지 않는다 | 탐색을 재귀로 바꾸는 것 |
  | **선언** | `_CO_NON_VARIANT_DIRS` — 깊이가 못 막는 퇴화형(`deprecated/harness/`)을 막는다 | 그 상수를 비우는 것 |

  `LINT-MR` 은 변형을 **이름으로** 찾으므로 "디렉토리 부재 — 건너뜀" 으로 빠진다.
  `LINT-FREEZE` 는 위 표대로 **면제 대상이 아니다** — 매니페스트가 보관소 경로를
  가리키므로 여기 있는 동결 파일도 그대로 해시 검사를 받는다.

  > 이 항목은 처음에 "`_SCOPE_RULES` 가 제외한다" 고 적혀 있었다. **사실이 아니었다** —
  > `_SCOPE_RULES` 는 트리 *안의* 경로를 보지 변형 이름을 보지 않는다. 당시 제외는
  > 깊이에서 **우연히** 나온 것이었고, 상수를 비우는 변이에서 테스트가 생존해 드러났다.
  > 그래서 두 겹을 각각 적고 `DeprecatedStoreTest` 의 두 케이스로 하나씩 고정했다.
- 되살릴 때는 `_VARIANTS_WITH_*` 에 다시 등재하고 **미러부터 맞춘다**
  (옮긴 시점의 drift 가 그대로 남아 있다). 동결 둘(`claude/`·`openai/`)은
  `freeze-manifest.json` 의 경로를 같은 커밋에서 되돌린다 — 해시는 안 바뀐다.

## 여기 있는 것

| 변형 | 무엇이었나 | 되살릴 이유가 생긴다면 |
|---|---|---|
| `claude/` | Phase 0 baseline 스냅샷 (**동결 — 지금도 해시 강제**) | 하네스의 출발점을 비교할 때 |
| `openai/` | Codex 호스트 변형 (.codex/ 구조, **동결 — 지금도 해시 강제**) | codex 어댑터 실구현 시 |
| `claude.gstack*` 5종 | 기능 서술 계보 (auto→design→wiki→orch) | 특정 오버레이만 쓰는 다운스트림이 생길 때 |
| `claude.hermes` · `claude.productmgr` · `claude.productnw` | hermes/pm/nw 오버레이 계보 | 해당 기능을 단독으로 배포할 때 |
| `claude.aif` | 판정 설계 (RLAIF/CAI) — 적합도 함수 없는 쪽 | — `localllm.aif` 가 수치 비교가 가능한 쪽이었다 |
| `localllm.aif` | d-2 + 판정 설계 — **A/B 수치 비교가 가능했던 유일한 aif 변형** | aif 판정 실측을 재개할 때 |
| `localllm.nem` | d-2 + nemotron — 모델 축 대조군 | 모델 A/B 를 재개할 때 |

> **아는 손실을 적어 둔다**: `localllm.aif` 는 무인 스위트로 부모와 A/B 수치 비교가
> 가능한 유일한 aif 변형이었고(ADR-020), `localllm.nem` 은 모델 축의 대조군이었다
> (ADR-021). 둘을 내리면 F028·F030 의 **실측 환경이 함께 비활성화**된다. 구조는
> 보존되지만 숫자는 더 나오지 않는다.
